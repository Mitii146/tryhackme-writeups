# Windows PowerShell

## Platform

TryHackMe

## Difficulty

Easy

## Overview

This room introduced the fundamentals of Windows PowerShell, including command discovery, file and directory management, system administration, networking, process management, and remote command execution.

## Commands Practiced

### Command Discovery

- Get-Command
- Get-Alias
- Find-Command
- Find-Module
- Install-Module

### File and Directory Management

- Get-ChildItem
- Set-Location
- New-Item
- Move-Item
- Remove-Item
- Get-Content

### System Information

- Get-ComputerInfo
- Get-LocalUser

### Networking

- Get-NetIPConfiguration
- Get-NetIPAddress
- Get-NetTCPConnection

### Process and Service Management

- Get-Process
- Get-Service

### Security and Remote Management

- Get-FileHash
- Invoke-Command

## Key Takeaways

- PowerShell is a powerful command-line shell and scripting language used for Windows administration and automation.
- Built-in cmdlets allow administrators to manage files, processes, services, users, and network settings efficiently.
- PowerShell can retrieve detailed system information and perform remote administration.
- File hashes can be generated to verify file integrity.
