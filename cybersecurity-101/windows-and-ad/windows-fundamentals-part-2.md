## Key Concepts

### System Configuration

mscconfig - is for advanced troubleshooting, and its main purpose is to help diagnose startup issues

### UAC

User Account Control - helps prevent unauthorized changes to the system.

### Computer Management

compmgmt - this utility has three primary sections:

- System Tools
- Storage
- Services and Applications

### System Information

msinfo32 - gathers information about computer and displays a comprehensive view of hardware, system components, and software environment, which you can use to diagnose computer issues.

### Resource Monitor

resmon - provides real-time, in-depth tracking of how your computer's hardware (CPU, memory, disk, and network) is being utilized by software

### System Configuration

cmd - built-in text-based interface. Instead of clicking icons, you type instructions directly to the operating system

### Registry Editor

regedit - used to view, modify, and manage the Windows Registry

## Key Takeaways

- Learned about built-in Windows administration and troubleshooting tools.
- Learned how to gather system information using msinfo32.
- Learned the purpose of UAC and how it helps protect Windows systems.
- Learned how to monitor system resource usage with Resource Monitor.
- Learned the role of the Windows Registry and how to access it with regedit.
